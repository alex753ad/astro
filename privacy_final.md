## 2. Состав обрабатываемых персональных данных

2.1. При регистрации и использовании Сервиса Оператор обрабатывает следующие данные:

- адрес электронной почты;
- имя (имя пользователя), указанное при регистрации;
- дата, время и место рождения (город, координаты) — вводятся Пользователем для расчёта натальной карты;
- IP-адрес и технические данные устройства (User-Agent, данные о браузере) — собираются автоматически;
- push-токен устройства — при подключении push-уведомлений;
- данные об активности в Сервисе: построенные карты, транзиты, использованные функции;
- сведения о платежах: суммы, даты, тарифы, статусы транзакций (без реквизитов банковских карт);
- краткая сводка контекста диалога с AI-астрологом — обобщённое описание тем обращений, используемое для персонализации последующих ответов;
- дата и время предоставления согласия, а также редакции документов, с которыми Пользователь согласился;
- данные календаря Google (названия, время и содержание событий) — только при добровольном подключении интеграции с Google Calendar, см. раздел 3.

2.2. Оператор не собирает специальные категории персональных данных (расовое происхождение, состояние здоровья, политические взгляды и т. п.) и биометрические персональные данные. Данные банковских карт Оператору не передаются и не хранятся — их обрабатывает платёжный сервис ЮKassa.

2.3. Оператор не запрашивает сведения о семейном положении, доходах, месте работы, паспортные данные и иные документы, удостоверяющие личность.

3.1. При добровольном подключении Google Calendar Сервис запрашивает доступ к событиям календаря Пользователя через протокол OAuth 2.0. Доступ используется исключительно для отображения и создания событий в планере Astrea Timeline.

3.2. Данные, полученные через Google Calendar API, не передаются третьим лицам и не используются в рекламных целях.

3.3. Пользователь может отозвать доступ в любой момент через настройки своего аккаунта Google: myaccount.google.com/permissions.

3.4. Использование и передача информации, полученной от Google API, осуществляется в соответствии с Политикой использования данных пользователей Google API, включая требования об ограниченном использовании (Limited Use). В частности: данные Google Calendar используются только для функций планера внутри Сервиса; данные Google не используются для показа рекламы; данные Google не передаются третьим лицам, за исключением случаев, необходимых для работы Сервиса или требуемых законом; доступ к данным Google предоставляется только лицам, которым он необходим для выполнения служебных обязанностей.

## 4. Цели обработки персональных данных

4.1. Персональные данные обрабатываются в следующих целях:

- идентификация Пользователя и предоставление доступа к Сервису;
- расчёт натальных карт, транзитов и иных астрологических данных с помощью Swiss Ephemeris;
- генерация AI-интерпретаций на основе введённых астрологических данных;
- синхронизация событий с Google Calendar — только при наличии явного согласия Пользователя;
- направление уведомлений (email, push) о транзитах, прогнозах, событиях;
- обработка платежей, формирование чеков и налоговый учёт;
- техническое обеспечение безопасности: защита от несанкционированного доступа, выявление злоупотреблений;
- ответы на обращения Пользователей.

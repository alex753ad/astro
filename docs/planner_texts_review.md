## 6. «е» вместо «ё»

Проверены по смыслу (без «своей», «твоей» и т. п.):
счетов → счетов (без ё — верно), счет → **счёт** (Солнце 2-й), отчетов →
**отчётов** (Меркурий 3-й), тяжелые/Тяжелая/тяжелой → **тяжёлые/Тяжёлая/тяжёлой**
(Меркурий 8-й, Марс 4-й, Юпитер 4-й), легких/легкие → **лёгких/лёгкие** (Венера
3-й), свое → **своё** (Венера 3-й, 4-й, 6-й; Юпитер 5-й; Сатурн 6-й, 10-й;
Нептун 4-й/10-й), дает → **даёт** (Марс 1-й; Уран 2-й/8-й; Нептун 6-й/12-й;
Плутон 4-й/10-й), четкий/четкую → **чёткий/чёткую** (Марс 6-й, Сатурн 6-й,
9-й), ведет → **ведёт** (Юпитер 10-й), ее → **её** (Нептун 4-й/10-й), живет →
**живёт** (Нептун 4-й/10-й).

«е» вместо «ё» может быть и в словах вне списка сканера — сплошную вычитку на
«ё» не делал.

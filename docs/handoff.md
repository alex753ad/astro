**Расхождения и ловушки:**
- Флаг `day_event._sky_on` читается по сессии ORM-карты: у копий (`SimpleNamespace`, dict) он выключен — ручки решают флаг по ORM-карте и передают `sky` явно. CRM — исключение: флаг по астрологу (`crm.crm_sky`), не по карте клиента.
- Пилотные письма Consistency не видит — держат тесты; расчёт через общую функцию ядра (`sky.sky_events`).
- Heredoc в Bash съедает `\n`, `\r`, `\.` в python-строках — правки с обратной косой только через Edit/Write.
- Тесты: `.venv/Scripts/python.exe -m pytest -q -x --tb=short <файлы>`; скрипты с импортом `backend` — `PYTHONPATH=.`.
- Прод-Redis: один DB 0 на всё, maxmemory нет (noeviction), `mem_limit: 512m` — см. plans/redis_split.md.
- Два `authFetch` с разной семантикой: `api/client.js` отдаёт `Response`, заголовки не трогает; `useAuth().authFetch` (пропом в CRM, PaymentHistory и др.) отдаёт разобранный JSON, бросает `ApiError` и всегда ставит `Content-Type: application/json` — для потоков, blob и FormData не годится. Refresh у обоих один (`refreshSession`, дедуп `refreshInFlight`) — гонки нет. Голый `fetch` с Bearer — ловушка `src/api/bareFetch.test.js`.
- eslint (`frontend/eslint.config.js`) — только `no-undef`; `public/*`, а не `public/**`, иначе `!public/sw.js` не срабатывает. Тесты React — `react-test-renderer` (jsdom нет).
- Фоновые ожидания CI/деплоя система снимает при нехватке памяти — не ждать, итог даёт `notify-deploy`.

**Не трогать:** пилотная программа (бот, письма, автопонижение, CRM бывших, вкладка) — остаётся; `/transits/interpret` и `lunar_engine.get_slow_aspects` — бэклог шага 7; политику Redis; старые миграции; неотслеживаемые файлы владельца (корневой `handoff.md` и др.; свои — в `private/`).

# Карточка «Добавь виджет на главный экран» — отчёт и план (флаг `widget`)

02.10.2026. **Согласовано владельцем 02.10.2026, код — после того, как
виджет заработает на его телефоне (скриншот диагностики пришлёт):**
тексты — вариант Б; показ с 3-го дня; инструкция в «Ещё» — да, для всех,
текст из плана; показы и добавления — в еженедельную сводку.

## Как работает системный запрос

- `AppWidgetManager.requestPinAppWidget` (Android 8+): лаунчер показывает
  свой диалог «Добавить виджет?», человек жмёт «Добавить» — виджет встаёт
  на главный экран сам, без поиска в списке. Разрешений не нужно.
- Работает только если лаунчер умеет: `isRequestPinAppWidgetSupported()`.
  Samsung One UI, Pixel и большинство прошивочных лаунчеров умеют; часть
  сторонних (и старые Xiaomi MIUI) — нет.
- Работает только для **включённого** компонента: сначала флаг → `setEnabled`,
  потом карточка. Если компонент не включился (как у вас сейчас), карточку
  не показываем — запрос всё равно бы не сработал.
- Отказ в диалоге приложению не сообщается. Узнаём по факту: при возврате в
  приложение спрашиваем, сколько виджетов стоит (`status().placed`, уже есть
  в диагностике).
- В плагин добавляется один метод `requestPin()` (~15 строк Java).

## Кому показывать

Все условия сразу:
1. Флаг `widget` включён, вошли в аккаунт, есть карта.
2. Компонент включён, лаунчер умеет закреплять, виджета на экране нет.
3. Человек открывает приложение не первый день: с **3-го дня**, в который
   он открывал приложение (счётчик дней на устройстве). Первые дни заняты
   карточкой первой недели и подсказками.
4. В ленте в этот момент нет карточки первой недели и «Недели вперёд» —
   больше одной карточки сверху не ставим.

## Где и когда

- В ленте, над прогнозом «сегодня», той же формы, что карточка первой
  недели.
- Пропадает навсегда, как только виджет появился на экране (проверка при
  каждом возврате в приложение).

## Как не надоедать

- «Не сейчас» — карточка скрывается на 14 дней.
- Второе «Не сейчас» — больше не показываем никогда.
- Нажали «Добавить», но виджета так и нет (отказались в диалоге) — то же,
  что «Не сейчас».
- Итого не больше двух показов на человека.

## Если лаунчер не умеет закреплять

Карточку не показываем: кнопка, которая ничего не делает, хуже, чем ничего.
Предлагаю взамен строку в «Ещё» → «Уведомления» (или отдельным пунктом) с
инструкцией, как добавить вручную, — только если скажете. По умолчанию не
делаю.

| Заголовок | Добавь виджет на главный экран | Твой день на главном экране |
| Текст | Фаза Луны и главное событие дня — сразу на экране телефона, без входа в приложение. | Фаза Луны и главное событие дня — без входа в приложение. |

## Что нужно от вас

1. Тексты: вариант А или Б (или правки).
2. С какого дня показывать — с 3-го или иначе.
3. Строка-инструкция для лаунчеров без закрепления — нужна или нет.
4. Считать ли показы и добавления в еженедельной сводке (как сторис) —
   отдельная таблица и строка в сводке.

## План после «да»

1. Плагин: `requestPin()`.
2. `mobile/lib/widgetPin.js` — правило показа (дни, отказы, условия) +
   тест; карточка в ленте рядом с карточкой первой недели.
3. `npm run build:mobile`, APK вам; правило — docs/mobile.md, «Виджет „День“».

⚠️ Зависит от починки «виджета нет в списке»: пока компонент не
включается, карточка показываться не будет по условию 2.

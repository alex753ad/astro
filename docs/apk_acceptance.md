# Приёмка APK на устройстве

Короткий список перед каждой выдачей APK (решение владельца 29.09.2026).
Ссылка на этот файл идёт в каждом сообщении к APK в Telegram — шаблон подписи
в [deploy.md](deploy.md), «Каждая сборка APK для приёмки».

Синастрии, соляра и CRM здесь нет намеренно: в приложении их нет, и они пока
не работают.

## Каждая сборка

- [ ] **Версия.** «Ещё» → внизу «Версия 0.1.0-N»: N совпадает с номером
      сборки из подписи.
- [ ] **Вход и выход.** Вход почтой и паролем, выход, повторный вход. Почта с
      заглавной буквы тоже входит. Сброс пароля кодом доходит на почту.
- [ ] **Лента.** Открывается сегодняшний день, прогноз на день не запасной
      текст, прокрутка в прошлое и вперёд без рывков, 👍/👎 принимается.
- [ ] **Окно предложения.** На бесплатном тарифе закрытая функция открывает
      окно с тарифом по правилу предложений, цена та же, что на /pricing.
- [ ] **/pricing.** aristeatime.ru/pricing: четыре тарифа, 0 / 790 / 2490 /
      7990 ₽ — те же цены и названия, что в окне предложения в приложении.
- [ ] **Планер.** В ленте есть окна планера и полоса «сейчас»; на бесплатном
      закрытые окна подписаны, а не пропали.
- [ ] **PDF.** «Карта» → «PDF-отчёт →»: «Собрать» доходит до готового,
      «Открыть» показывает файл, «Поделиться» открывает системный лист.
- [ ] **Push.** Разрешение запрашивается один раз; уведомление приходит при
      свёрнутом приложении, нажатие открывает приложение.
- [ ] **Уведомления при первом запуске.** Строка диагностики: «Ещё» →
      нажать «Версия 0.1.0-N» (появится «· диагностика уведомлений») →
      «Уведомления» — вверху мелкая строка: прогноз показан, тумблер,
      разрешение, отсчёт, карточка, последняя проверка (повод → вывод:
      экран / молча / ждать / ничего) и включение (сервер / устройство /
      не вышло). Повторное нажатие на версию её убирает.
  - **Android 12, свежая установка.** Удалить приложение, поставить APK,
    зарегистрировать новый аккаунт, дождаться текста прогноза. Экрана нет и
    не должно быть. Сразу после загрузки прогноза в «Уведомления» тумблер
    устройства включён; в строке «прогноз загрузился → молча», «включение:
    сервер» (без сервисов Google — «устройство»). «не вышло» — повторится
    при следующем возврате на ленту или в приложение.
  - **Android 13+, свежая установка.** То же до прогноза. Экран не поверх
    прогноза: перейти на другую вкладку и вернуться на «Ленту» (или свернуть
    и развернуть) — экран «Присылать прогноз каждое утро?». «Включить» →
    системный запрос → «Разрешить»: тумблер включён, «включение: сервер».
    «Не сейчас» — экран больше не появляется; в строке «отсчёт с …»;
    карточка в ленте через 3 дня (быстрее — перевести дату телефона),
    крестик убирает её навсегда. Дважды отказать в системном запросе — в
    карточке «Открыть настройки», ведёт на экран уведомлений приложения;
    разрешить там и вернуться — тумблер включается сам.
  - Гостю ничего из этого не показывается.
- [ ] **Канал поддержки.** Обращение из приложения («Ещё» → «Написать в
      поддержку») доходит в @aristeatimesupport.

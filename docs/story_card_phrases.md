# Фразы для карточки дня в сторис

Флаг `story_card`. Первое лицо, без рода, до 32 знаков. Ключ — натальная точка × тон
аспекта (как `PLANET_ADVICE` в `backend/day_event.py`, но без транзитной планеты).
Тон: гармония — трин/секстиль, напряжение — квадрат/оппозиция, начало — соединение.

Асцендент и Середина неба: фраза показывается, событие — нет (вместо строки «Луна × …» —
фаза Луны), решение владельца 01.10.2026.

Согласовано владельцем 01.10.2026 с тремя правками (Луна/гармония, Нептун/гармония,
убывающая Луна).

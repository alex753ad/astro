# Удержание D1/D7/D30

Решение владельца 30.09.2026. Метрика только для администратора, без флага.

## Что считается

- **Активный день** — строка в `user_activity_days` (человек, день по Москве,
  платформа, флаги дня). Пишет `backend/activity.py` из `get_current_user`:
  любой авторизованный запрос, кроме фоновых (`BACKGROUND_PATHS`: токен FCM,
  план локальных уведомлений). Гости не считаются — у них нет id.
- **День регистрации — 0.** D1 — был в день 1; D7 — хоть раз в дни 7–13;
  D30 — хоть раз в дни 30–36 (`RETENTION_WINDOWS`, `backend/metrics.py`).
  Окно в неделю, а не строгий день N: при наших объёмах строгий день — шум.
- В знаменателе — только те, чьё окно уже закончилось.
- Не считаются администраторы и `revenue_excluded`.
- ⚠️ **Задним числом не заполнялось** (решение владельца). Когорта — только
  зарегистрированные с первого записанного дня; без этого все, кто пришёл
  раньше, выглядели бы ушедшими. Первый D7 — через ~2 недели после выкладки,
  D30 — через ~5.

## Разбивки

- **Платформа** — где человек был в первый активный день; если в тот же день
  и там, и там — «приложение». ⚠️ Приложение узнаётся по `Origin:
  https://localhost` (webview Capacitor), а не по `X-Client-Platform`: этот
  заголовок ставят только запросы авторизации. В ячейке видно и куда
  вернулся («прил. N · сайт M»).
- **Тариф — текущий** (решение владельца, в админке сноска): платят как раз
  оставшиеся, поэтому у платных удержание выглядит выше.
- **Флаг** — делит когорту на тех, у кого флаг был включён в день 0 или 1, и
  остальных. Флаги берутся из строки активного дня: в `feature_flags` только
  текущее состояние.

## Где смотреть

- `/admin` → «Пилот» → «Удержание по неделям регистрации»
  (`GET /api/v1/admin/retention?platform=&tier=&flag=`).
- Telegram: понедельник 09:00 МСК, `tasks.retention_weekly`, последние 8
  недель и итоги по платформам. Шлётся `send_support_message` — туда же, куда
  утреннее сообщение самопроверки (так просил владелец). ⚠️ Это
  `TELEGRAM_SUPPORT_CHAT_ID`; корневой CLAUDE.md называет этот чат каналом
  @aristeatimesupport, а владелец — личным чатом. Сводка придёт туда же, где
  он видит утреннее сообщение, в любом случае; расхождение описаний — вопрос
  к владельцу 30.09.2026.
